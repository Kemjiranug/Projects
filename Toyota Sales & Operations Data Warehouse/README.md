## Toyota Sales & Operations Data Warehouse
*(Data Warehouse & Analytics Project)*

📅 Duration: 01/2026 – Present  

---

### Overview  
This project focuses on designing a data warehouse to support sales and operations analysis. It transforms raw data into a structured format suitable for reporting and analytics.

---

### Key Features  
- Analyzed business requirements for sales and operations  
- Defined KPIs, facts, and dimensions  
- Designed a star schema with a clear fact table grain  
- Created dimension tables (Date, Product, Customer, Location)  
- Developed a data dictionary and documentation  

---

### Process  
1. Requirement analysis  
2. Data modeling (conceptual → logical)  
3. Schema design (star schema)  

---

### Project Status  
- Phase 1 completed (Requirement analysis & dimensional design)  
- Phase 2 in progress (BI dashboards & analytics)
