## Character Search System
*(Information Retrieval & Search Engine)*

📅 Duration: 08/2025 – 11/2025  

---

### Overview  
This project focuses on building a search system to efficiently retrieve character information using Elasticsearch. It explores different search techniques to improve query accuracy and relevance.

### Key Features  
- Built a search system using Elasticsearch  
- Implemented lexical, fuzzy, and semantic search techniques  
- Analyzed query behavior and search relevance  
- Applied basic ranking logic to improve result accuracy  

---

### Key Insights  
- Fuzzy search improves tolerance to misspellings  
- Semantic search enhances relevance for ambiguous queries  
- Combining multiple techniques leads to better search performance
