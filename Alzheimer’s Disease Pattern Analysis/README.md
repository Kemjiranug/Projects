## Alzheimer’s Disease Pattern Analysis
*(Data Analysis & Visualization Project)*

📅 Duration: 08/2025 – 11/2025  

---

### Overview  
This project explores patterns of cognitive decline using data analysis and visualization techniques to better understand Alzheimer’s disease.  
It focuses on identifying whether patients can be distinguished based on cognitive and behavioral features.

### Key Features  
- Performed exploratory data analysis (EDA) on cognitive and behavioral data  
- Applied PCA and t-SNE for dimensionality reduction  
- Compared linear and nonlinear representations of the dataset  
- Visualized clustering patterns to better understand data structure  

---

### Key Insights  
- PCA does not clearly separate Alzheimer’s and non-Alzheimer groups, indicating limited linear separability  
- t-SNE reveals clearer clusters and local structure in the data  
- Cognitive and behavioral features play an important role in grouping patterns  
- Nonlinear methods are more suitable for capturing underlying relationships in the data  

---

### Technical Details  
- Preprocessed data (handling missing values and feature selection)  
- Standardized features before applying PCA and t-SNE  
- Applied PCA for global variance analysis and t-SNE for local structure visualization  
- Tuned t-SNE parameters (e.g., perplexity) to improve cluster visualization
